01 About

Engineering from the interface to the infrastructure

I’m a Full Stack Software Engineer with 4+ years of software development experience. I work across web, mobile, databases, cloud infrastructure and AI integrations, with a particular interest in scalable backend systems.

My production work includes REST APIs, payment integrations, recommendation systems, analytics integrations and administrative dashboards, from Java services supporting financial operations to React Native applications and their Node.js backends.

In practice, that means writing code others can maintain, designing backends that stay reliable, measuring and improving performance, and working closely with the team. I keep learning, and adopt new technology where it solves a real problem.

  • Web and mobile

    React, Next.js and React Native interfaces, including administrative dashboards.

  • Backend and APIs

    REST APIs and services with Node.js, Express.js and Java with Spring Boot.

  • Data and cloud

    Relational and document databases, containers, CI/CD and cloud deployment.

  • AI and product signals

    Recommendation systems, AI-powered features, payments and analytics integrations.
